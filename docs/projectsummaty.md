# Project Summary

This project predicts Mesenchymal Stem Cell count using machine learning.

A structured biotechnology dataset was prepared with environmental, nutritional, culture, and viability variables.

EDA identified major correlations.

Regression models were trained to estimate final stem cell count.

Main finding:
Culture duration, confluence, and viability strongly influence predicted stem cell yield.

This project demonstrates biotechnology + AI integration for predictive bioprocess analytics.
