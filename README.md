# 📖 Project Overview

This project develops a **machine learning-based prediction system** for estimating **Mesenchymal Stem Cell (MSC) count** using biological and environmental culture variables.

The goal was to build a realistic **industrial biotechnology data analytics workflow**, starting from raw experimental data and ending with predictive modeling.

✨ This project combines:

🧪 Stem Cell Biology  
📊 Data Analytics  
🤖 Machine Learning  
📈 Predictive Modeling

---

# 🎯 Problem Statement

Stem cell growth depends on many interconnected factors.

Manual prediction becomes difficult because:

🔹 Multiple variables interact at the same time  
🔹 Biological systems behave non-linearly  
🔹 Missing values occur in real datasets  
🔹 Cell culture conditions change dynamically

### ✅ Target Variable

# 🧬 Stem_Cell_Count

The model predicts final stem cell count using 19 process variables.

---

# 📂 Dataset

Two datasets were used:

## 🧪 1. Industrial Simulation Dataset

✔ ~7% missing values
